# Burger House API

Это backend-часть для приложения "Burger House". Проект представляет собой набор микросервисов, написанных на Java 21 и Spring Boot, и предоставляет API для управления заказами, доставкой, оплатой и пользователями. 

## Структура проекта

Проект разделен на несколько независимых модулей (микросервисов), которые взаимодействуют друг с другом:

* `common-libs` — общие DTO, модели, енамы и события Kafka, которые переиспользуются в других сервисах.
* `user-service` — сервис для работы с пользователями, регистрация, аутентификация и выдача JWT-токенов.
* `order-service` — сервис управления заказами. Обрабатывает корзину, создание заказа и статусы. Взаимодействует с другими сервисами по HTTP и через Kafka.
* `payment-service` — сервис оплаты. Заглушка для проведения платежей, после успешной оплаты кидает событие в брокер сообщений.
* `delivery-service` — сервис доставки. Назначает курьеров, рассчитывает примерное время прибытия (ETA) и обновляет статусы доставки.

## Стек технологий

* Java 21
* Spring Boot
* PostgreSQL (основная база данных)
* Apache Kafka (для асинхронного взаимодействия между сервисами)
* MapStruct (для маппинга сущностей в DTO)
* JWT (для авторизации)
* Swagger / OpenAPI (документация API)

## Как запустить локально

В корне проекта есть `docker-compose.yaml`, который поднимает всю необходимую инфраструктуру: PostgreSQL и Kafka (с Zookeeper).

1. Поднимите инфраструктуру через Docker:
   ```bash
   docker-compose up -d
   ```

2. Запустите все микросервисы. Вы можете использовать вашу IDE, либо собрать и запустить их через Gradle. Обратите внимание, что каждый сервис должен быть запущен на своем порту (порты прописаны в application.yml каждого модуля).

   Сборка проекта:
   ```bash
   ./gradlew build
   ```

## Документация API

После запуска микросервисов документация Swagger будет доступна по стандартным путям (если подключена зависимость springdoc). Например, для одного из сервисов это может быть:
`http://localhost:<PORT>/swagger-ui.html`

Также в корне проекта лежит файл `Burger_House_API.postman_collection.json`. Вы можете импортировать его в Postman, там собраны все основные запросы для тестирования API.

## Тесты

В проекте настроены модульные и интеграционные тесты для проверки бизнес-логики сервисов. Запустить все тесты разом можно командой:

```bash
./gradlew test
```
