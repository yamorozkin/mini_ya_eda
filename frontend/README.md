# Delivery App Frontend

Красивый и функциональный фронтенд для приложения доставки еды, построенный на React и Bootstrap.

## Функциональность

✅ **Аутентификация**
- Регистрация новых пользователей
- Вход в систему
- Генерация резервных кодов двухэтапной аутентификации
- Управление профилем

✅ **Каталог товаров**
- Просмотр доступных товаров с картинками
- Фильтрация и поиск

✅ **Корзина покупок**
- Добавление товаров в корзину
- Редактирование количества
- Удаление товаров
- Расчет итоговой стоимости

✅ **Заказы**
- Создание заказов с адресом доставки
- История заказов пользователя
- Просмотр деталей заказа
- Отслеживание статуса доставки

✅ **Оплата**
- Оплата заказов
- Поддержка различных способов оплаты

✅ **Администрирование**
- Добавление новых товаров (для администраторов)
- Загрузка изображений товаров
- Установка цен

## Требования

- Node.js 14+
- npm или yarn

## Установка и запуск

### 1. Установка зависимостей

```bash
cd frontend
npm install
```

### 2. Запуск в режиме разработки

```bash
npm start
```

Приложение откроется в браузере по адресу [http://localhost:3000](http://localhost:3000).

### 3. Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `build/`.

## Интеграция с Backend

Приложение подключается к API на:
- **Order Service**: http://localhost:8080/api (товары, заказы)
- **User Service**: http://localhost:8083/api (аутентификация, профиль)

С поддержкой:
- JWT токенов в заголовках
- Автоматический refresh при истечении
- Обработка ошибок

### Эндпоинты

#### Аутентификация (user-service)
- `POST /api/v1/auth/register` - Регистрация
- `POST /api/v1/auth/authenticate` - Вход
- `POST /api/v1/auth/generate-backup-codes` - Генерация резервных кодов

#### Товары (order-service)
- `GET /api/items` - Получение всех товаров
- `POST /api/items` - Создание товара (только админ)

#### Заказы (order-service)
- `GET /api/orders` - Получение всех заказов пользователя
- `GET /api/orders/{id}` - Получение деталей заказа
- `POST /api/orders` - Создание заказа
- `POST /api/orders/{id}/pay` - Оплата заказа

#### Доставка (delivery-service)
- `GET /api/deliveries/streets` - Получение доступных улиц для доставки

## Технологии

- **React 18** - UI framework
- **React Router 6** - Маршрутизация
- **Bootstrap 5** - CSS фреймворк
- **React Bootstrap** - Компоненты Bootstrap для React
- **Axios** - HTTP клиент
- **JS Cookie** - Управление cookies (хранение JWT)

## Особенности

🔐 **Безопасность**
- JWT токены хранятся в cookies
- Токены автоматически добавляются в каждый запрос
- Проверка аутентификации на защищенных маршрутах

🎨 **Дизайн**
- Адаптивный дизайн (мобильный, планшет, десктоп)
- Bootstrap компоненты для консистентного внешнего вида
- Красивые карточки товаров с изображениями

⚡ **Производительность**
- Ленивая загрузка компонентов
- Локальное управление состоянием (Context API)
- Оптимизированные запросы к API

## Процесс использования

### Для обычного пользователя:

1. **Регистрация/Вход** - Перейдите на页面 регистрации или входа
2. **Просмотр каталога** - На главной странице доступны все товары
3. **Добавление в корзину** - Нажмите "Добавить в корзину"
4. **Оформление заказа** - Перейдите в корзину, выберите улицу из списка (Main Street, Oak Avenue, Pine Road, Elm Street, Maple Lane, Cedar Boulevard, Birch Way) и введите номер дома (1-100)
5. **Оплата** - На странице деталей заказа выберите способ оплаты и оплатите
6. **Отслеживание** - Смотрите статус в "Мои заказы"
7. **Резервные коды** - Генерируйте их в профиле для безопасности

### Для администратора:

1. Войдите с аккаунтом администратора
2. Нажмите "Добавить товар" в навигации
3. Заполните название, цену и URL картинки
4. Товар сразу появится в каталоге для всех пользователей
